# admission-portfolio-v1 — lab pre-registration (synthetic, isolated)

Status: **frozen before execution**. Date: 2026-09-22. Track: **synthetic
lab** (`docs/DUAL_TRACK_PLAN.md`). Isolated from production: no product code,
no real-window logs, no bridge. P3v4 (commit `44c0124`) is the standing
comparator.

## 1. Hypothesis

A **typed evidence portfolio** - guaranteed slots for evidence classes -
beats score-only selection (P3v4 and its ablations) on questions that need
complementary evidence (origin, contradiction, rationale), without losing
the controls (current state, supersession, multi-fact, absence, volume),
under the same 4000-character budget and joint availability+precision gates.

## 2. Substrate (new, lab-owned fixture)

`eval/fixtures/admission_portfolio_v1/` generated by
`eval/gen_admission_portfolio_v1.py` (deterministic, no LLM): 80 cases
(8 scenarios x 10) with known gold. Scenarios and gold:

| scenario | situation | gold |
|---|---|---|
| `current_state` | old and current value of the same setting | current only |
| `supersession` | fact corrected later (marker present) | correction only |
| `origin` | question asks where a fact comes from | fact + origin record |
| `contradiction` | two values disagree, no supersession marker | **both** (open contradiction) |
| `related_context` | decision + its rationale, both needed | decision + rationale |
| `multi_memory` | two complementary facts | both |
| `no_answer` | topic absent | abstain |
| `distractor_volume` | one unique match among 41 distractors | the match |

Sample hash frozen in the manifest at generation; the validator test proves
byte-identical regeneration.

## 3. Policies (same candidates, no LLM)

- **P1** margin 0.50, **P2** margin 0.90 (references).
- **P3v4** the frozen candidate module (`memory_machine.admission_p3v4`).
- **P4-abl** (ablation): same scoring/floors/removal as P4 but **no slots** -
  fill by gain order up to the cap (isolates slot structure from "more
  items").
- **P4** (primary): signals scored exactly as P3v4; eligible = not
  superseded-removed and `rare >= 0.30`; **cap 3 items**; slots filled in
  order, each item added when unselected and within the 4000-char budget:
  1. **supersession**: highest-gain correction candidate (if any).
  2. **current state**: highest-gain survivor with `temporal == 1`.
  3. **contradiction pair**: best unselected pair with >= 3 shared tokens,
     token Jaccard in [0.30, 0.70] and both `rare >= 0.40` - the pair is
     delivered together (preserve both while unresolved).
  4. **origin** (only when the question carries an origin cue:
     where/from/source/origin/came/comes/veio/quem): highest-gain survivor
     with a provenance marker (source|doc|paper|readme|commit|according
     to|per the).
  5. **reserve**: remaining capacity by gain.
  Non-pair items are skipped when Jaccard > 0.70 against the selected set.

## 4. Metrics

Availability (gold retrieved / 110), precision (gold / delivered),
delivered count, mean characters, per-scenario availability and precision.

## 5. Gates (P4; all required)

- **G1** availability >= 0.90.
- **G2** precision >= 0.70.
- **G3** beats P3v4: availability(P4) > availability(P3v4) **and**
  precision(P4) >= precision(P3v4) - 0.05.
- **G4** targeted wins: availability(P4) > availability(P3v4) on **both**
  `contradiction` and `origin`.
- **G5** slots are the cause: availability(P4) > availability(P4-abl) on at
  least one targeted scenario, with no targeted regression.
- **G6** cap and budget respected (<= 3 items/case; <= 4000 chars).
- **G7** determinism.

## 6. Expected readings (declared, not gates)

P3v4 misses the contradiction pair (redundancy/temporal pick one) and the
origin combination (lexical overlap favors one side). P4 delivers both in
those scenarios; P4-abl improves over P3v4 only where the cap matters.
Availability ~0.95-1.00, precision ~0.70-0.80.

## 7. Stop rules

Any gate fail: report, change nothing, re-fit nothing; the lab result informs
which layer to develop next after the real window closes. Passing gates
**never** promotes: it only prepares a candidate for a future real window
starting from zero (own pre-registration). This is a lab fixture; results are
non-evidence for product performance. Overfitting risk of template fixtures
applies in full.

## 8. Execution protocol

Harness `eval/admission_portfolio_v1.py`, outputs
`eval/results/admission_portfolio_v1/report.json` and `report.md`,
`tests/test_admission_portfolio_v1.py` (regeneration equality, determinism,
recorded verdicts), proof regenerated, one primary run plus determinism
rerun, execution record appended, all committed.


## Execution record (2026-09-22)

Recorded run on the frozen lab fixture; determinism rerun identical.

| policy | availability | precision | delivered | max/case |
|---|---:|---:|---:|---:|
| P1 margin50 | 0.818 | 0.562 | 160 | 5 |
| P2 margin90 | 0.746 | 0.578 | 142 | 5 |
| **P3v4 (frozen)** | **0.909** | **0.833** | 120 | 2 |
| P4-abl | 0.909 | 0.714 | 140 | 3 |
| P4 (portfolio) | 0.909 | 0.714 | 140 | 3 |

Gates: G1 **true** (0.909 >= 0.90); G2 **true** (0.714 >= 0.70); G3
**false** (availability equal to P3v4, not greater); G4 **false**
(`contradiction` and `origin` are 1.00 for P3v4 already); G5 **false** (no
targeted gain over the ablation); G6 true; G7 true; `all_pass` **false**.

Findings:

- **The hypothesis is not supported by this fixture**: P3v4 already delivers
  both records in `contradiction` and `origin` (its cap-2 and floors fit the
  pairs), so the typed slots add no availability and cost precision
  (0.833 -> 0.714) by filling the third slot with weak candidates.
  `P4-abl` (no slots, same cap) is identical to P4 - the slots contribute
  nothing measurable here.
- **The single real gap is retrieval**: `related_context` is 0.50 for every
  policy - the rationale record never reaches the delivered set. The pair
  rule did not fire (decision and rationale share fewer than 3 tokens), and
  no slot structure can fix a candidate that ranking buries. This repeats
  the earlier lesson: admission cannot compensate for ranking.
- Declared expectations missed: P3v4 was predicted to fail contradiction and
  origin; the fixture did not create that tension (pairs rank high and fit
  the cap). Recorded as a fixture-design limitation, not re-fitted.

Stop rules applied: gates failed, nothing changed, nothing re-fitted. The
lab evidence says: do not advance the typed-portfolio architecture as
specified; the next lab iteration (if any) must create scenarios where the
pair competes against high-gain decoys and target retrieval of rationale
records. This remains lab-only evidence; no production impact.
