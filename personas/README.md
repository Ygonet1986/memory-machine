# Fichas de personagem

`lia/v1.json` é um modelo inicial para revisão conjunta, não uma ficha aprovada
para qualquer pessoa. Cada aprovação cria uma cópia privada no root isolado da
pessoa, personagem e continuidade. Mudanças posteriores geram nova versão e
mantêm o histórico; editar o modelo no repositório não modifica roots existentes.
